## 작업 요약
명함 관리 모바일 화면의 업로드/촬영 버튼 높이와 아이콘 크기를 줄이고, 가져오기 버튼 아이콘을 업로드와 다른 스프레드시트 가져오기 형태로 변경했다.

## 변경 파일 목록
- `src/app/page.cards/view.pug`: 가져오기 버튼 아이콘을 업로드 아이콘과 다른 스프레드시트 가져오기 아이콘으로 변경.
- `src/app/page.cards/view.scss`: 모바일 업로드/촬영 버튼을 44px 행 버튼으로 축소하고, 작은 화면에서도 세로 대형 버튼으로 바뀌지 않도록 조정.
- `src/app/page.my_card/view.pug`: 정보 입력 카드 헤더의 `명함 관리` 이동 버튼 제거.
- `src/app/page.my_card/view.scss`: 모바일에서 상단 액션 영역이 빈 공간을 만들지 않도록 숨김 처리.
- `src/app/layout.sidebar/view.pug`: 모바일 아이콘 메뉴의 접근성 이름 유지를 위해 nav 링크에 `aria-label` 추가.

- `devlog.md`, `devlog/2026-06-09/025-mobile-card-actions-topnav-icons.md`: 작업 이력 기록.
