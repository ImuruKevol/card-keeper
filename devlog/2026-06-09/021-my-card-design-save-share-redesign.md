# 021. 내 명함 모바일 디자인 저장·공유 동작 및 베이스 재구성

## 사용자 요청

- 모바일에서 명함 이미지 카드 헤더 오른쪽 끝에 저장 버튼을 추가한다.
- 디자인 색상과 베이스 변경점이 저장 시 반영되도록 한다.
- 복사 시 모달을 제거한다.
- 이미지 공유 시 이미지 저장까지 되는 버그를 수정한다.
- 모던, 플로우 디자인을 다시 구성한다.

## 변경 파일

- `src/app/page.my_card/view.pug`
  - 모바일 Preview 헤더 오른쪽에 디자인 저장 버튼을 추가했다.
  - 색상 input의 `input`/`change` 이벤트를 모두 감지하도록 보강했다.
- `src/app/page.my_card/view.scss`
  - Preview 헤더를 좌우 정렬하고 모바일 전용 디자인 저장 버튼 스타일을 추가했다.
- `src/app/page.my_card/view.ts`
  - 디자인 저장 버튼용 `saveDesign` 진입점을 추가했다.
  - 공유 링크 복사 기본 동작에서 성공 모달을 제거했다.
  - 이미지 공유 실패/미지원 시 다운로드 fallback을 제거해 이미지 저장이 같이 발생하지 않도록 했다.
  - 모던/플로우 명함 베이스 배경을 새 구조로 재구성했다.
- `devlog.md`
- `devlog/2026-06-09/021-my-card-design-save-share-redesign.md`

## 남은 리스크

- 이미지 공유는 Web Share API 지원 여부에 의존하며, 미지원 브라우저에서는 저장으로 fallback하지 않고 안내 모달만 표시한다.
