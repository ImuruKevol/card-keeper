# import 결과 미리보기 전환

- **ID**: 003
- **날짜**: 2026-06-09
- **유형**: 기능 추가

## 작업 요약
명함 가져오기 모달 하단 미리보기를 원본 데이터 표가 아니라 현재 컬럼 매핑 결과 기준의 저장 예정 데이터 표로 변경했다.
매핑되지 않은 컬럼을 메모에 추가하는 옵션도 결과 미리보기에 즉시 반영되도록 했다.

## 원문 요청사항
```text

스트리밍 응답은 사용하지 않습니다. 작업이 끝난 뒤 변경 요약, 확인한 내용, 남은 리스크만 정리하세요.
이 작업의 세션 단위는 아래 리뷰 ID입니다. 리뷰 ID가 같으면 같은 Codex 히스토리 맥락으로 이어서 처리하세요.

## 사용자 요청

하단의 데이터 미리보기 말고, 데이터들이 가져오기를 했을 때 어떻게 들어가는지 미리보기를 보여주도록 수정해줘.
```

- `src/app/page.cards/view.pug`: 하단 표를 원본 데이터 미리보기에서 가져오기 결과 미리보기로 변경
- `src/app/page.cards/view.scss`: 결과 미리보기 행 번호 열 스타일 추가
- `devlog.md`, `devlog/2026-06-09/003-import-result-preview.md`: 작업 이력 추가
