# 020. 폴드 펼침 화면의 내 명함 모바일 기준 통일

## 사용자 요청

- Fold7 펼침 화면에서 데스크톱도 모바일도 아닌 중간 배치가 나타나므로, 폴드에서도 모바일 기준으로 통일한다.

## 변경 파일

- `src/app/layout.sidebar/view.scss`
  - 공통 상단 레이아웃의 모바일 전환 기준을 `1080px 이하` 또는 터치 coarse 환경으로 확장했다.
- `src/app/page.my_card/view.scss`
  - 내 명함 화면의 모바일 전용 배치 기준을 폴드 펼침 폭까지 확장했다.
  - Preview 우선 배치, 모바일 디자인 섹션, 정보 입력 영역 저장 버튼, 숨김 처리된 데스크톱 액션이 폴드에서도 동일하게 적용되도록 했다.
- `src/app/page.my_card/view.ts`
  - 명함 이미지 확대 보기의 모바일 판정 기준을 같은 조건으로 확장했다.
- `devlog.md`
- `devlog/2026-06-09/020-my-card-fold-mobile-breakpoint.md`

## 확인 결과

- `wiz_project_build(clean=false)` 성공.
- `git diff --check` 성공.
- `npm run test:e2e` 성공: 6개 테스트 통과.
- Playwright 884x1104 터치 뷰포트로 폴드 펼침 화면에 가까운 조건을 검증했다.
  - 공통 상단 내비게이션이 모바일 기준으로 표시됨.
  - 내 명함 Preview가 정보 입력보다 먼저 표시됨.
  - 모바일 디자인 섹션이 표시되고 데스크톱 디자인 섹션은 숨김 처리됨.
  - 저장 버튼이 정보 입력 패널 내부에 표시됨.
  - 명함 이미지 확대 뷰어가 열림.
- Playwright 1440x900 데스크톱 폭에서는 기존 데스크톱 배치가 유지됨을 확인했다.

## 남은 리스크

- 실제 Fold7 브라우저의 CSS viewport 값은 브라우저/배율/주소창 상태에 따라 달라질 수 있으나, 폭 기준과 터치 입력 기준을 함께 적용해 대부분의 펼침 상태를 모바일 기준으로 처리하도록 했다.
