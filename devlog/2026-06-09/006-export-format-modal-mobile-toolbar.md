# 내보내기 포맷 선택 모달 및 모바일 아이콘 툴바 적용

- **ID**: 006
- **날짜**: 2026-06-09
- **유형**: UI 개선

## 작업 요약
CSV/XLSX 개별 내보내기 버튼을 하나의 `내보내기` 버튼으로 통합하고, 클릭 시 모달에서 XLSX 또는 CSV 포맷을 선택해 내려받도록 변경했다.
모바일 툴바는 가져오기/내보내기/명함 등록 3개 액션을 한 줄 아이콘 버튼으로 표시하고 텍스트 라벨은 숨기도록 조정했다.

## 원문 요청사항
```text
# ReviewOps Codex 작업 요청

아래 요청을 현재 프로젝트 루트에서 처리하세요. 필요한 파일을 직접 수정하고, 마지막 응답은 한국어로 간결하게 작성하세요.
스트리밍 응답은 사용하지 않습니다. 작업이 끝난 뒤 변경 요약, 확인한 내용, 남은 리스크만 정리하세요.
이 작업의 세션 단위는 아래 리뷰 ID입니다. 리뷰 ID가 같으면 같은 Codex 히스토리 맥락으로 이어서 처리하세요.

## 사용자 요청

- csv, xlsx 버튼들은 내보내기 버튼 하나로 합쳐버리고, 누르면 모달로 포맷을 선택할 수 있도록 수정해줘.
- 모바일에서 버튼들은 1열로 표시하고 텍스트는 표시하지 않도록 해줘.
```

## 변경 파일 목록
- `src/app/page.cards/view.ts`: 내보내기 모달 상태, 포맷 선택, 확인 시 export 실행 흐름 추가
- `src/app/page.cards/view.pug`: CSV/XLSX 버튼을 내보내기 버튼으로 통합하고 포맷 선택 모달 추가
- `src/app/page.cards/view.scss`: 내보내기 모달 스타일 및 모바일 아이콘 전용 툴바 배치 추가
- `devlog.md`, `devlog/2026-06-09/006-export-format-modal-mobile-toolbar.md`: 작업 이력 추가
