# 016. 내 명함 이미지 레이아웃과 연락처 클릭 동작 개선

## 사용자 요청

- 명함 이미지의 텍스트 크기, 빈 여백, 전체 레이아웃을 개선한다.
- 명함 관리 상세 모달의 휴대폰, 전화, 이메일, 웹사이트는 별도 버튼 없이 텍스트 클릭으로 동작하게 한다.
- 라인 디자인을 제거하고 다른 느낌의 베이스로 교체한다.
- 플로우 디자인은 유지하되 오른쪽 그래픽이 텍스트 가독성을 해치지 않게 한다.
- 제공된 계정으로 실제 명함 이미지와 공유 이미지를 확인한다.

## 변경 파일

- `src/app/page.my_card/view.ts`
  - 캔버스 명함 렌더러의 글자 크기, 좌우 컬럼 폭, 연락처 영역 패널, 하단 장식 균형을 조정했다.
  - `라인` 베이스를 선 패턴이 없는 `모던` 베이스로 교체했다.
  - `플로우` 그래픽을 오른쪽 연락처 영역에서 분리해 왼쪽 하단 중심으로 배치했다.
- `src/app/page.cards/view.pug`
  - 상세 모달의 링크 가능한 값은 별도 아이콘 버튼 대신 값 텍스트 자체를 링크로 렌더링하도록 변경했다.
- `src/app/page.cards/view.scss`
  - 상세 모달 텍스트 링크 스타일을 추가하고 기존 링크 아이콘 버튼 스타일을 제거했다.
- `src/route/my-card-share/controller.py`
  - 공개 공유 페이지의 휴대폰, 전화, 이메일, 웹사이트를 텍스트 링크로 표시하도록 추가했다.
- `devlog.md`
- `devlog/2026-06-09/016-my-card-layout-contact-actions.md`
