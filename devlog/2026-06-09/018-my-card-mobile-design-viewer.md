# 018. 내 명함 모바일 디자인·저장 위치 및 가로 확대 보기 개선

## 사용자 요청

- 모바일에서 저장 버튼은 명함 이미지 쪽이 아니라 정보 입력 쪽에 둔다.
- 디자인(색상과 베이스)은 명함 이미지 바로 아래에 둔다.
- 명함 이미지를 누르면 모바일 기준으로 가로로 돌려 화면을 꽉 채워 표시하는 기능을 추가한다.

## 변경 파일

- `src/app/page.my_card/view.pug`
  - 모바일 저장 버튼을 정보 입력 패널 내부로 이동했다.
  - 모바일 전용 디자인 섹션을 Preview 이미지 바로 아래에 추가했다.
  - 명함 캔버스 클릭/키보드 진입 시 모바일 확대 뷰어를 열도록 연결했다.
  - 확대 뷰어 마크업과 닫기 버튼을 추가했다.
- `src/app/page.my_card/view.scss`
  - 모바일에서 데스크톱 디자인 섹션을 숨기고 모바일 디자인 섹션을 노출했다.
  - 확대 뷰어를 고정 오버레이로 표시하고, portrait 환경에서는 명함 이미지를 회전해 크게 보이도록 스타일링했다.
- `src/app/page.my_card/view.ts`
  - 확대 뷰어 상태와 이미지 데이터 생성 로직을 추가했다.
  - 지원 브라우저에서는 전체화면 및 landscape orientation lock을 best-effort로 시도하고, 실패 시 회전 오버레이로 fallback한다.
