# import 컬럼 매핑 검증 및 메모 병합 옵션 보완

- **ID**: 002
- **날짜**: 2026-06-09
- **유형**: 기능 추가

## 작업 요약
명함 가져오기 컬럼 매핑에서 같은 대상 필드가 중복 선택되면 오류를 표시하고 가져오기 실행을 막도록 보완했다.
매핑되지 않은 컬럼 값을 메모에 `컬럼명: 값` 형태로 일괄 병합하는 체크박스를 추가하고, 매핑 영역을 2열 컴팩트 그리드로 조정했다.

## 원문 요청사항
```text
# ReviewOps Codex 작업 요청

아래 요청을 현재 프로젝트 루트에서 처리하세요. 필요한 파일을 직접 수정하고, 마지막 응답은 한국어로 간결하게 작성하세요.
스트리밍 응답은 사용하지 않습니다. 작업이 끝난 뒤 변경 요약, 확인한 내용, 남은 리스크만 정리하세요.
이 작업의 세션 단위는 아래 리뷰 ID입니다. 리뷰 ID가 같으면 같은 Codex 히스토리 맥락으로 이어서 처리하세요.

## 사용자 요청

- 매핑이 중복되었을 때는 에러를 표시하면서 가져오기를 못하게 해야해. 예시로 쓰고 있는 엑셀 파일에 "이름" 컬럼도 이름으로 매핑되고, "명함첩 이름" 컬럼도 이름으로 매핑이 되는 문제가 있어.
- 매핑이 되지 않은 정보들을 일괄적으로 메모 컬럼에 정리해서 넣을 수 있는 체크박스를 추가해줘.
- 굉장히 깔끔하게 잘 개발이 되긴 했는데, 컬럼 매핑 쪽이 height가 길어지면서 스크롤이 생기는게 살짝 아쉬워.
```

## 남은 리스크
- 실제 예시 엑셀 파일 원본으로 브라우저에서 import 전체 플로우를 직접 수행하지는 못했다.
- 메모 병합은 매핑되지 않은 컬럼만 대상으로 하며, 이미 특정 필드로 매핑한 컬럼은 메모에 중복 저장하지 않는다.
