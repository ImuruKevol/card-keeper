# 017. 내 명함 플로우 베이스 복원 및 모바일 Preview 우선 배치

## 사용자 요청

- 플로우 디자인은 이전 디자인이 더 좋았으므로, 배경 이미지 느낌은 되돌리고 위치만 이동한다.
- 모바일에서 명함 관리 화면으로 이동하는 버튼을 삭제한다.
- 모바일 저장 버튼 위치를 조정한다.
- 모바일에서 내 명함 Preview가 맨 위에 먼저 보이도록 한다.

## 변경 파일

- `src/app/page.my_card/view.ts`
  - `플로우` 베이스를 이전 오른쪽 곡선형 배경에 가깝게 되돌리고, 연락처 텍스트를 덜 침범하도록 오른쪽 가장자리로 이동했다.
- `src/app/page.my_card/view.pug`
  - 상단 저장 버튼과 모바일 전용 저장 버튼을 분리했다.
  - 모바일 숨김 처리를 위해 명함 관리 이동 링크에 식별 클래스를 추가했다.
- `src/app/page.my_card/view.scss`
  - 모바일에서 Preview 패널이 입력 폼보다 먼저 배치되도록 순서를 조정했다.
  - 모바일에서 명함 관리 이동 링크와 데스크톱 저장 버튼을 숨기고, Preview 아래 모바일 저장 버튼을 표시하도록 조정했다.
