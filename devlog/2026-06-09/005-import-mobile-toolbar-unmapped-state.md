# import 모바일 툴바와 가져오지 않음 매핑 표시 개선

- **ID**: 005
- **날짜**: 2026-06-09
- **유형**: UI 개선

## 작업 요약
모바일에서 가져오기/CSV/XLSX/명함 등록 버튼이 각각 한 줄을 차지하지 않도록 620px 이하에서도 2열 배치를 유지하게 조정했다.
컬럼 매핑에서 `가져오지 않음` 상태인 행은 중복 오류와 구분되는 별도 색상으로 표시되도록 보완했다.

## 원문 요청사항
```text
# ReviewOps Codex 작업 요청

아래 요청을 현재 프로젝트 루트에서 처리하세요. 필요한 파일을 직접 수정하고, 마지막 응답은 한국어로 간결하게 작성하세요.
스트리밍 응답은 사용하지 않습니다. 작업이 끝난 뒤 변경 요약, 확인한 내용, 남은 리스크만 정리하세요.
이 작업의 세션 단위는 아래 리뷰 ID입니다. 리뷰 ID가 같으면 같은 Codex 히스토리 맥락으로 이어서 처리하세요.

## 사용자 요청

- 모바일에서 가져오기, csv, xlsx, 명함 등록 버튼이 한줄씩 차지하고 있어서 너무 많은 height를 잡아먹고 있어.
- 가져오지 않음 매핑 정보들은 중복 매핑 에러 빨간색 표시처럼 해서 다른 색상으로 표시해줘.
```

- `src/app/page.cards/view.scss`: 모바일 툴바 2열 유지, 가져오지 않음 매핑 행 색상 추가
