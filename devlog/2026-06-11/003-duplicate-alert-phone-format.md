# Android 알림 전화번호 하이픈 표시 적용

- **ID**: 003
- **날짜**: 2026-06-11
- **유형**: UX 개선

## 작업 요약
Android 앱 수신 알림에서 휴대폰/전화번호가 숫자만 이어져 보이는 경우 하이픈을 추가해 표시하도록 개선했다.
웹 명함 중복 모달에 적용했던 이전 변경은 범위에 맞지 않아 되돌리고, Android 알림 텍스트 조립부에만 표시용 번호 포맷을 적용했다.
휴대폰, 서울 지역번호, 일반 지역번호, 050 계열, 대표번호, 국제번호 `82` 계열 등 자릿수별 표시 케이스를 처리했다.

## 원문 요청사항
```text
웹 화면은 상관없고 안드로이드 앱의 알림을 말하는거였어.

알림에 보면 번호를 보여줄 때 "-" 없이 숫자만 나열이 되어있는데 중간에 "-"을 추가해서 가독성을 향상시켜줘.
번호 자릿수에 따른 여러 경우의 수가 있으니 반드시 고려하고.
```
