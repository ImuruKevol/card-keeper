- **ID**: 010
- **날짜**: 2026-06-05

## 작업 요약
명함 등록 모달과 상세 확인 모달을 별도 UI로 분리했다.
목록에서 명함을 선택하면 읽기 전용 상세 확인 모달이 열리고, 별도 편집 버튼을 눌러야 입력 필드가 활성화되도록 변경했다.
읽기 전용 상세 모달의 각 필드에는 복사 아이콘 버튼을 추가하고, 복사 성공 시 해당 버튼만 초록색 체크 상태로 잠시 바뀌게 했다.

## 사용자 요청

명함 등록 모달과 정보 수정(상세 정보 확인) 모달은 완전히 다른 UI/UX가 적용되어야 해.
상세 정보 확인 모달은 해당 사람의 정보를 깔끔하고 빠르고 정확하게 확인할 수 있어야 해.
상세 정보 확인 모달에서는 편집 버튼을 별도로 두고, 눌러야 편집이 가능하게 해야해. 그리고 편집 모드가 아닐 때는 각 필드값에 대해 복사 아이콘 버튼을 추가해서 빠르게 복사할 수 있게 해야해. 복사 버튼을 누르면 그냥 초록색 체크표시로만 바뀌게 했다가 돌아가게 해서 최대한 간결하게 복사 완료를 알려주면 돼.

## 남은 리스크
- 복사 기능은 브라우저 클립보드 API 또는 `execCommand('copy')` fallback에 의존한다. 권한이 막힌 특수 브라우저 환경에서는 체크 표시가 나타나지 않을 수 있다.
- 상세 모달의 이미지 교체는 제공하지 않고, 편집 모드에서는 텍스트 필드만 수정한다.
